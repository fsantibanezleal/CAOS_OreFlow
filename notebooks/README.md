# OreFlow notebooks / Notebooks OreFlow

A bilingual didactic path through comminution, flotation kinetics and machine-learning validation. Every notebook reads committed OreFlow records and imports no copied engine method. Start at `en/README.md` or `es/README.md`; see the template's [notebook guide](../docs/guides/08_notebooks.md).

Run: `scripts/setup.ps1 -Notebooks` on Windows or `scripts/setup.sh --notebooks`; validate with `python scripts/check_notebooks.py` and `python scripts/run_notebooks.py --check --tmp <temp-root>`.
