# OreFlow cases

The web and bake use the twelve authored circuits in `data-pipeline/pipeline/cases/catalog.py`. Each case declares ore family, feed and circuit parameters, source status, KPI ranges and variants. These are authored research scenarios, not measured plant operating records.

The committed records are in [`data/derived/cases/`](../../data/derived/cases/); detailed source and model notes are in [`docs/use-cases/`](../use-cases/) and [`docs/methodologies/`](../methodologies/). The identifiers are `copper_porphyry_soft`, `copper_porphyry_hard`, `iron_magnetite_fine`, `gold_free_milling`, `phosphate_clay`, `nickel_sulphide`, `copper_molybdenum`, `copper_oxide`, `zinc_sulfide`, `mixed_ore_high_clay`, `low_grade_copper` and `refractory_gold`.
