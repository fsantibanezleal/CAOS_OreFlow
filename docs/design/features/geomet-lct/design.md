# Design: measured locked-cycle test benchmark

The external source is the latest open version of the GeoMet dataset, Zenodo record 7051975 (concept DOI 10.5281/zenodo.6336137), CC BY 4.0. `flotation.csv` has 53 rows; one lacks LCT, leaving 52 measured locked-cycle test recoveries in fractions. The raw CSV remains ignored locally; the compact predictions/artifact can be redistributed with attribution. Source MD5 is `f2e90da6bfa81de1261177ee85a91570` and is checked before use.

Predictors are the five measured assay columns `Cu ppm`, `Fe ppm`, `S ppm`, `Si ppm`, `Al ppm`, log1p-transformed. `fr` and `xr` are excluded because their exact semantics and relation to LCT are not established; location and `HOLEID` are split/visualization metadata, not model features. Median imputation and standardization are fitted only on training folds. A global training-mean baseline, fixed-alpha ridge, random forest and Gaussian process are evaluated on identical rows. Five grouped folds leave holes out. A harder three-fold test leaves disjoint X-coordinate zones out; zone assignment is by each hole's mean X, so all samples from one hole remain in one zone. Both tests are within one deposit, not across mines.

The artifact contains per-row out-of-fold predictions, fold labels, error metrics and complete source/split metadata. A Benchmark subtab shows model scores plus linked observed–predicted and sample-position plots, with selection and units. It does not replace the existing HZDR or simulator lanes. The measured LCT response cannot calibrate OreFlow's operating-point simulator: the source does not contain its reagent, grind or residence controls.

A local-only batch path fits the three learned models on all 52 reference tests after evaluation and writes a source-pinned joblib checkpoint into ignored `models/`. It accepts a CSV carrying exactly the five named assay features (extra identifier columns may pass through), performs the same log1p/fold-independent preprocessing, emits a CSV with three predictions in percent, and flags missing values and any assay outside the reference's featurewise training range. This is within-dataset predictive exploration, not a transfer guarantee. Untrusted checkpoint files are never loaded automatically from remote URLs.

Primary sources: [GeoMet dataset](https://zenodo.org/records/7051975) and [Hoffimann et al., Mathematical Geosciences (2022)](https://doi.org/10.1007/s11004-022-10013-1). The paper explicitly identifies limited samples and covariate shift as concerns.
